## 使用

1. 下载并完整解压配套包。
2. 打开 `Body_Language.ppt`，保留同目录的 `media` 文件夹。
3. 第 6 页视频：`media/Slide6_Video.mp4`。
4. 第 7 页视频：`media/Slide7_Video.mp4`。
5. 第 8 页听力音频：`media/Slide8_Audio.mp3`。

旧版 PPT 导出无法保留原嵌入媒体；原音视频已逐字节保存在配套包中，未删减。页面媒体图片或图标添加了文件链接，实际播放取决于 PowerPoint/WPS 的兼容和安全设置。若链接打不开，请直接打开对应媒体文件播放。建议授课前检查播放。仅下载 PPT 文件不包含这些音视频。

开场白与逐页教学提示见配套包中的 `Teaching_Notes.txt` 和课件备注。原二维码保留，链接有效性请课前确认。


## Using Language：20 页合并优化版

这份新课件按两个分册的原页序合并为 20 页，采用紫色与珊瑚橙的摄影海报风格，与上一份 Reading and Thinking 的插画风格区分。

- [下载完整 PPTX（37.16 MB）](Unit4_Using_Language_Optimized.pptx)：全部原音视频嵌入，无需另下载媒体包。
- [查看静态排版 PDF](Unit4_Using_Language_Preview.pdf)：不播放动画或音视频。
- [查看开场白与逐页教学提示](Unit4_Using_Language_Teaching_Notes.txt)。

动画包含 65 个教师点击控制的呈现步骤：听力答案逐项揭示、证据与推断分步呈现、角色对话按回合展示，以及文化释义与总结归纳。课件没有自动翻页或自动播放。

8 个独立媒体文件（7 个视频、1 个音频）与用户提供的两个分册逐字节一致，16 个原播放入口及其原媒体设置均保留。重复的媒体文件共享嵌入资源，以控制文件体积。校验了文件结构、媒体解码、动画目标、20 页教学备注与文字显示；尚未在 Microsoft PowerPoint 中实际点击播放，请授课前在放映模式下检查媒体和动画效果。

身体动作可提供线索，但不能单独证明说谎；传统动作的释义需要结合情境。新增教学提示作了相应说明。
