课件共 21 页，包含优化后的配色、排版、主题插图、分步淡入动画，以及开场白和教学提示。

- [PPTX 优化版（26.11 MB）](Body_Language_Optimized.pptx)：推荐使用，原第6、7、8页音视频完整嵌入，保留动画与教学备注。

- [完整配套包（推荐，15.54 MB）](Body_Language_PPT_Full_Package.zip)：包含旧版 PPT 和原始音视频。

点击文件进入 GitHub 文件页后，点击 **Download raw file（下载原始文件）**。浏览器会将文件保存到默认下载文件夹；也可选择“另存为”，将位置设为桌面。

## 使用

1. 下载并完整解压配套包。
2. 打开 `Body_Language.ppt`，保留同目录的 `media` 文件夹。
3. 第 6 页视频：`media/Slide6_Video.mp4`。
4. 第 7 页视频：`media/Slide7_Video.mp4`。
5. 第 8 页听力音频：`media/Slide8_Audio.mp3`。

旧版 PPT 导出无法保留原嵌入媒体；原音视频已逐字节保存在配套包中，未删减。页面媒体图片或图标添加了文件链接，实际播放取决于 PowerPoint/WPS 的兼容和安全设置。若链接打不开，请直接打开对应媒体文件播放。建议授课前检查播放。仅下载 PPT 文件不包含这些音视频。

开场白与逐页教学提示见配套包中的 `Teaching_Notes.txt` 和课件备注。原二维码保留，链接有效性请课前确认。
